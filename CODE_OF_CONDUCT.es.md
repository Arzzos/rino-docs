# Código de conducta (Contributor Covenant 2.1, resumido)

> In English: [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).

## Compromiso

Nos comprometemos a que participar en Rino Docs sea una experiencia libre de acoso para
todas las personas, sin importar edad, origen, identidad o nivel. Es un proyecto educativo
en etapa Beta; paciencia con quienes empiezan.

## Conducta esperada

- Lenguaje amable e inclusivo (el idioma del proyecto es español o inglés).
- Respeto a otros puntos de vista; enfoque en hechos técnicos y evidencia.
- Aceptar crítica constructiva; un tema por hilo.

## Conducta inaceptable

- Acoso, insultos, doxxing o publicar datos privados (incluidos datos de alumnos en `.docx`/`.pdf`).
- Spam, autopromo o proselitismo en issues, PRs o salidas PDF.

## Aplicación

Las personas mantenedoras pueden editar, cerrar o eliminar aportes que violen este código
y suspender a reincidentes. Reportes: aviso privado de seguridad en GitHub o contacto del
campo `author` en `package.json`. Todo reporte se trata con confidencialidad.
