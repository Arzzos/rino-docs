# Tutorial: your first portfolio in 10 minutes

1. Open the app, fill in **Profile** (student, career, group).
2. Go to **Subjects** → upload the instrumentation file — **DOCX recommended** — and press Validar/editar to fix detected data.
3. Optionally add a diagnostic evaluation.
4. Go to **Evidence** → 3-step wizard (Datos → Contenido → Revisar), attach images/code/tables, generate the FO-205P11000-14 PDF.
5. Go to **Portfolio** → check fixed group order, drag to reorder inside each group, generate the clickable PDF and preview it.

Everything stays offline in your browser (IndexedDB). Drafts autosave for 15 days.
